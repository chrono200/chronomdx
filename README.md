## Requirements

- Node.js (use a current LTS release)
- npm
- A WhatsApp account for pairing the bot

## Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/chrono200/chronomdx.git
   cd chronomdx
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure the bot using the environment/configuration template supplied with the project. Keep private credentials and session files out of Git.
4. Start the bot:
   ```bash
   npm start
   ```

## Important

- Keep the bot running on a host that supports persistent Node.js processes.
- Review the project configuration before deploying it to a hosting provider.
